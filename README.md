# Perfect Boutique · Demo

Demo de catálogo mayorista para Perfect Boutique Mayorista: pedido por tallas y colores, precio al mayor o al detal automático, envío del pedido por WhatsApp y panel de inventario de muestra.

Sitio estático: `index.html` y la carpeta `img/`. Se despliega en Vercel sin configuración (Framework Preset: Other).

Para personalizar, edita el bloque `CONFIG` al inicio del script en `index.html` (número de WhatsApp, prendas para precio al mayor, planes) y la lista `SEED` de productos.
